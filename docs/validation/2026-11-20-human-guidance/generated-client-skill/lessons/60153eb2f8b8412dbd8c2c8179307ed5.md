## 适用场景

CU Demo Orders 的订单查询页

## 参数

- orderId：用户本次请求的订单号；示范值不能固定复用

## 操作方法

### 1. 填写订单号

在 OrderNumber 中填写本次 orderId

预期状态：输入值等于 orderId

控件识别线索（每次重新观察）：
```json
{"automationId":"OrderNumber","controlType":"Edit"}
```

### 2. 查询并等待

触发 Query，并等新 Completed 标记

预期状态：结果订单号匹配，查询序号已更新

控件识别线索（每次重新观察）：
```json
{"automationId":"Query","controlType":"Button"}
```

## 本次任务的成功标准

本次订单号、状态、金额和新的查询序号均一致

## 异常与恢复

- 结果仍旧时继续等待；找不到入口时请求辅导
